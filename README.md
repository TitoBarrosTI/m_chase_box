## 🔎 About

MCacheBox is a lightweight desktop application built with **Python + PySide6**.

It connects to an **IMAP email account** and allows fast searching, filtering, and inspection of emails.
The tool was designed to simplify large mailbox analysis and help users quickly locate relevant messages.

Simple, fast, and focused on productivity.

---

## ✨ Features

```
- IMAP email search
- Multiple filter support
- Fast message listing
- Clean desktop interface
```

## ⚙️ Configuration (REQUIRED)

Before running the application, you must define the following environment variable:

```
EMAIL_PASS=your_app_password
```
### What is an App Password?

An App Password is a special password generated by your email provider to allow external applications to access your account securely.

It is different from your regular account password and can be revoked at any time.

### How to get it

- Gmail: search for "Google App Password" in your account security settings
- Yahoo Mail: search for "Yahoo App Password" in your account security settings
- Outlook / Hotmail: App Passwords may not be available for all accounts

Make sure 2-step verification (2FA) is enabled, as most providers require it to generate an App Password.

⚠️Notes
- All accounts must use an App Password (regular account passwords are not supported)
- IMAP must be enabled in your email provider settings

## ✅ Tested Providers

The application has been tested with the following email providers:

- Gmail
- Yahoo Mail

⚠️Notes
- Outlook / Hotmail accounts may require additional security configuration and might not support App Passwords in all cases
- IMAP must be enabled and accessible for the account to work properly

Other providers may work if they support IMAP and App Password authentication, but compatibility is not guaranteed.

## 🔐 Security & Privacy

```
MCacheBox connects to email accounts using the standard IMAP protocol.

The application does not store passwords.
Login credentials are used only to establish the IMAP session.
No data is transmitted to external servers.
All operations occur locally on the user's machine.
For Gmail accounts, an App Password may be required when two-factor authentication is enabled.
```
